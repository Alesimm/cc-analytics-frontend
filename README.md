# CC Analytics - Frontend

Plataforma de gestión deportiva integral y análisis táctico orientada al club Colo-Colo. Proyecto desarrollado para la asignatura de Desarrollo Fullstack II.

## Seguimiento de Tareas por Integrante

### Alexander Simpertigue
* **Repositorio y Estructura:** Inicialización del proyecto en GitHub con `.gitignore` y creación de la arquitectura de carpetas (`pages/`, `css/`, `js/`, `assets/`) para garantizar un entorno escalable.
* **Tecnologías Base:** Integración de Tailwind CSS (vía CDN) y FontAwesome para el diseño, junto con la creación del archivo `style.css` obligatorio por pauta.
* **Vistas HTML:** Desarrollo del esqueleto en `index.html` y generación de las 7 pantallas restantes para distribuir el trabajo.
* **Lógica Modular:** Segmentación de Vanilla JS en archivos específicos (`auth.js`, `app.js`, `storage.js`) para mantener el código limpio y facilitar la futura migración a React.
